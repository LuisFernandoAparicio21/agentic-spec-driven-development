A pointer to durable information that lives outside this memory system —
a technique, an external system, a location. Not a fact about current
project state (that's a project memory) and not a corrective rule (that's
feedback).

Example: "Manual test-case documents for endpoints without an automated
suite live at `<path>`, named `<Project>_<ticket>_<METHOD>_<resource>_
casos_prueba.<ext>`."

**How to apply:** When this reference is relevant — what kind of task
should make a future session go look at it.

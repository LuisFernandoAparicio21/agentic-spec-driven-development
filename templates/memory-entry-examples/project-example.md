The fact or decision, stated plainly and dated. Convert any relative dates
("next Tuesday") to absolute ones when writing this down — a memory read
weeks later needs the date to still make sense.

Example: "As of 2026-08-14, endpoint X ships with a known non-atomic
check-then-write race under concurrency, confirmed via a real concurrent-
request test. Documented and accepted for now — not silently patched."

**Why:** The motivation behind the fact — a constraint, a deadline, a
stakeholder decision. Project memories decay fast; the "why" is what lets a
future session judge whether the memory is still load-bearing or safe to
retire.

**How to apply:** How this should shape decisions until it's superseded or
resolved.
